My First Web Page  My first website, built while learning HTML and JavaScript.  ## What it does  - Shows a simple page with a heading, text, an image and a link - Has an input box and a button: type something, click "Say Hello", and the page greets you  ## What I learned  - Basic HTML structure (headings, paragraphs, images, links, labels, inputs) - How JavaScript finds elements with `getElementById` - How `addEventListener` runs code when a button is clicked - Debugging mismatched ids using the browser Console (F12)  ## How to run  Open `index.html` in any browser. No installation needed.  ## Next steps  - [ ] Style the page with CSS - [ ] Handle the empty-input case - [ ] Add a clear button - [ ] Build a to-do list app
